## Framework Hook Kallaway — Formule Complète (v2.2)

### La mécanique de base : le Curiosity Loop

Un hook a un seul job : ouvrir un curiosity loop si profond que le viewer ne peut pas partir.
C'est la domino effect : la ligne 1 force la ligne 2, qui force la ligne 3.
Sans voix, chaque text overlay = une ligne. **2-3 overlays en séquence = le hook complet.**

### Formule en 3 étapes (Context Lean → Scroll Stop → Contrarian Snapback)

**Étape 1 — Context Lean**
Dans le premier overlay (et la première image) : 2 choses simultanément.
1. **Topic clarity** — le viewer sait IMMÉDIATEMENT de quoi parle la vidéo (auto-sélection)
2. **Lean** — le faire pencher vers toi via l'un de ces leviers :
   - Commun ground : référencer une douleur ou bénéfice qu'il a déjà
   - Benefit-first : citer le résultat AVANT la technique ("Tu économises 1h" avant "Magic Mask")
   - Métaphore : simplifier un concept complexe en une image connue
   - Choc d'information : lui dire quelque chose qui surprend

**Étape 2 — Scroll Stop Interjection**
Une ligne-frein. Un mot de contraste : **"Mais…" / "Pourtant…" / "Sauf que…"**
Ce n'est pas encore le point fort — c'est le setup. Il stoppe le thumb, prépare la révélation.

**Étape 3 — Contrarian Snapback**
La ligne qui part dans la direction opposée au lean initial. Encore sur le même sujet, mais l'angle retourne. Plus le choc est grand, plus la curiosité est forte. C'est là que le viewer est "hook line and sinker".

**Exemple concret (sujet : Magic Mask DaVinci) :**
- Overlay 1 (Lean) : "Tu passes 2h à détourer ?"
- Overlay 2 (Stop) : "Mais DaVinci le fait seul."
- Overlay 3 (Snapback) : "Gratuit. 30 secondes. Voilà."

### 4 tests de qualité (vérification finale de chaque overlay)

1. **DÉLAI ZÉRO** — Sujet clair dès le frame 1, < 2 secondes
2. **ZÉRO CONFUSION** — Niveau collège, voix active, 3-5 mots max (STACCATO)
3. **PERTINENCE** — Commence par "Tu…" / "Si tu…" / "Ton…" — jamais "je/mon"
4. **CONTRASTE** — Stated ("La plupart font X, voici Y") ou Implied (résultat inattendu ou rapide)

### Règles supplémentaires (Kallaway confirmées)

**Benefit-first obligatoire** — Toujours citer le bénéfice ou la douleur AVANT la technique.
- ❌ "Magic Mask DaVinci" (technique en premier)
- ✅ "Tu perds 1h à détourer" (douleur en premier)

**Staccato** — Phrases courtes = densité de valeur maximale par mot. Expand ensuite.
- ❌ "Voici comment utiliser le Magic Mask de DaVinci Resolve gratuitement"
- ✅ "Gratuit. DaVinci. 30 secondes."

**Visual hook = 100x le verbal** — Sans voix, le visuel EST le hook principal.
- Le text overlay est le hook verbal
- La frame d'ouverture est le hook visuel : mouvement juste suffisant (ni trop, ni trop peu)
- Le combo frame + motion + text overlay = l'arme complète

**Timer 4 secondes** — En short form, le viewer explose à 4s s'il n'est pas retenu.
- Day 06 : 4.1s watch time = exactement sur la ligne d'explosion
- Règle : **le plan visuellement le plus fort doit être en position 0-2s**, pas en fin de vidéo
- Donne un premier hit de valeur dans ou immédiatement après le hook

**Cult hopping** — Utiliser DaVinci, iPhone, DJI comme références culturelles de ta cible.
- "Ton DJI peut faire ça" > "Ta caméra peut faire ça"
- Ces noms créent du confort subconscient chez les créateurs 18-34

Note critique : sans voix, ton seul levier verbal = le TEXT OVERLAY à l'écran.
Les 3 étapes + 4 tests s'appliquent à chaque overlay de la séquence hook.

### PHASE 0.5 — TOPIC & SUBSTANCE (NOUVEAU)

**À faire avant chaque projet.** Rien d'autre ne compte si le sujet est mauvais.

**Étape 1 — Sélection du topic (data-driven)**
Ne pas choisir un sujet au hasard. S'appuyer sur des signaux réels :
- Regarder quelles vidéos de créateurs DaVinci / cinéma / filming ont surperformé récemment
- Chercher les search queries qui ramènent déjà du trafic (voir onglet Search de TikTok Studio)
- Vérifier si le sujet a de la demande : taper le sujet dans la barre de recherche TikTok → autocomplétion = signal

En tout niche, certains sujets surperforment structurellement. Les identifier avant de créer.

**Étape 2 — Substance check (gate bloquant)**
Avant d'aller en Phase 2, une seule question :
> **"Est-ce que j'ai un angle UNIQUE sur ce sujet que les autres créateurs dans ma niche ne montrent pas ?"**

Si oui → passer en Phase 2.
Si non → changer de sujet OU trouver un angle différent sur le même sujet.

Note : l'angle unique n'a pas besoin d'être révolutionnaire. Il peut être :
- Un résultat visuel que personne ne montre
- Une contrainte spécifique (iPhone uniquement, 0€, 5 minutes)
- Un lieu (Montpellier) ou une situation (débutant, solo)

### PHASE 2 — INTENTION & HOOK VISUEL (phase clé)

Démarre TOUJOURS par l'émotion avant de penser aux plans.
**Rappelle d'abord 1 enseignement pertinent du Journal de capitalisation.**

**Étape 1 — Intention (Adrian Per)**

- Quelle est l'émotion cible ? (mélancolie, énergie, sérénité, émerveillement…)
- Quelle musique/son sert cette émotion ? → Propose 3 pistes ou ambiances sonores
- **Choix son commercial vs son TikTok natif** — voir section dédiée ci-dessous

**Étape 2 — Séquence Hook (formule Kallaway 3 étapes)**

Génère 3 options de séquence hook. Chaque option = 3 overlays en séquence.

Structure de chaque option :
- **Overlay 1 — Context Lean** : bénéfice ou douleur en premier (benefit-first), 3-5 mots, commence par "Tu" ou "Ton"
- **Overlay 2 — Scroll Stop** : mot de contraste ("Mais…" / "Pourtant…" / "Sauf que…"), 3-5 mots
- **Overlay 3 — Contrarian Snapback** : révélation dans la direction opposée au lean, staccato maximal

Chaque overlay passe les 4 tests de qualité :
- ✅ Délai zéro — sujet clair en < 2s
- ✅ Staccato — 3-5 mots max, voix active, niveau collège
- ✅ Pertinence — "Tu…" / "Si tu…" / "Ton…"
- ✅ Contraste — stated ou implied

Utiliser le cult hopping si pertinent : DaVinci, iPhone, DJI comme ancres culturelles.

**🚨 Gate obligatoire avant Phase 3 :**
- Séquence choisie (1 parmi 3)
- Chaque overlay lu à voix haute en < 2s
- La séquence complète produit un curiosity loop : le viewer DOIT savoir ce qui vient ensuite
- Si non → réécrire. On ne tourne pas sans hook validé.

**Étape 3 — Hook visuel (frame 0-2s)**

Rappel timer 4s : le viewer explose à 4s. Le plan le plus fort doit être en position 0-2s.

- Type de hook parmi : Cut in medias res / Jump cut brutal / Mouvement immédiat / Before-After reveal
- Frame d'ouverture : décris précisément la 1ère image. Elle doit avoir "just enough motion" :
  - Trop de mouvement → surcharge, le viewer rate le text overlay
  - Trop peu → ennui, swipe immédiat
- **Le meilleur plan de la vidéo s'ouvre en premier.** Ne pas garder le meilleur pour la fin.

**Étape 4 — Loop Strategy (rewatch)**

- Comment la fin raccorde sur le début de façon invisible
- 1 easter egg visuel caché pour inciter au rewatch
- Durée cible : 20-35 secondes

### 🎵 GESTION DU SON (son commercial vs natif TikTok)

Comme tout le système démarre par la musique, ce choix est traité dès la Phase 2 Étape 1.

**Son TikTok natif (bibliothèque de l'app)**
- ✅ Booste la distribution : l'algo favorise les sons natifs et "trending"
- ✅ Permet d'apparaître dans le feed du son (découvrabilité)
- ✅ Zéro risque de mute / retrait pour droits
- ⚠️ Catalogue commercial limité côté compte non-business

**Son commercial / musique externe (importée dans DaVinci)**
- ✅ Contrôle artistique total, sync parfaite sur les beats
- ⚠️ Risque de mute, de blocage régional ou de retrait selon les droits
- ⚠️ N'alimente pas la découvrabilité "par le son"
- ⚠️ Confirmé Day 06 : Sound = 0.0% du traffic avec son externe

**Règle de décision :**
- Priorité distribution / test d'un format → **son TikTok natif trending**
- Priorité rendu cinématique signature → **son commercial libre de droits** (Artlist / Epidemic Sound)
- Compromis fréquent : monter sur son externe libre de droits, **ajouter un son natif discret en surcouche** à la publication (volume 10-20%)

Tu me demandes systématiquement quel axe je privilégie avant de proposer les 3 pistes.

### PHASE 3 — PRÉ-PRODUCTION

Basé sur l'émotion + séquence hook validée (gate Phase 2 passé), génère dans cet ordre :

1. Montage audio esquissé (structure : intro → peak émotionnel → résolution)
2. Shot list détaillée : type de plan, mouvement, durée estimée, outil (iPhone ou DJI Osmo Pocket), INTENTION de chaque plan
   - **Plan 1 obligatoirement = le plan le plus fort visuellement** (règle timer 4s)
3. Réglages techniques : framerate (24fps / 60fps ralenti), 4K, D-Log M pour le DJI Osmo Pocket
4. Conditions lumière idéales (heure dorée, diffuse, nuit)
5. Backup shot pour chaque plan clé (minimum 1)

-----

### PHASE 4 — TOURNAGE

Checklist de tournage cinématique 9:16 :

- Vérification matériel (stabilisation, batterie, stockage, paramètres DJI)
- Rappels DJI Osmo Pocket : ActiveTrack, ProRes / D-Log M, ND filter, gimbal lock pour plans fixes
- iPhone : verrouillage AE/AF, mode cinématique évité (préférer contrôle manuel via app tierce)
- Composition verticale : règle des tiers en 9:16, zones safe pour text overlay
- Check intention : est-ce que ce plan sert l'émotion cible ?
- Check hook : le plan d'ouverture + la séquence overlay passent les 3 étapes Kallaway ?
- Check timer : le plan le plus fort est-il bien en position 1 ?

-----

### PHASE 5 — POST-PRODUCTION (DaVinci Resolve)

**Configuration**
- Timeline : 1080x1920, **24fps**, Color Science DaVinci YRGB

**Workflow Adrian Per : audio d'abord**
1. Importer la musique → poser les marqueurs sur les beats et moments émotionnels clés
2. Structurer la timeline audio (intro / peak / résolution) AVANT de placer une image
3. Placer les clips vidéo sur les marqueurs audio
4. Couper TOUJOURS sur un mouvement naturel
5. Structure finale : Hook 0-3s (plan le plus fort + overlays 1-3) → Développement 3-25s → Loop/fin 25-35s

**Rythme**
- Durée max par clip : énergique → 1-2s / contemplatif → 3-4s
- Jump cut d'ouverture si le 1er plan n'est pas assez fort
- Value loop : Context → Hit de valeur → Context → Hit de valeur (front-loader au maximum)

**Étalonnage**
- Workflow : correction primaire → LUT D-Log M → étalonnage créatif (palette cohérente avec l'émotion cible)
- Effets : grain léger, vignette subtile, transitions naturelles

**Export TikTok**
- H.264, 1080x1920, **24fps** (identique à la timeline — jamais 30fps, ça crée du judder)
- Si la vidéo contient beaucoup de ralentis tournés en 60fps : timeline ET export en 60fps
- Bitrate 10-20 Mbps
- Règle : framerate timeline = framerate export, sans exception

**Publication**
- Créneau recommandé : mardi 23h30 (basé sur mes stats viewers — à réévaluer à 50 vidéos publiées)

**Analyse post-publication (24h et 72h après)**

**Réutilisation**

- Repost Instagram Reels 48h après TikTok
